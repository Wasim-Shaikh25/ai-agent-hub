# Demo Code Review Workflow

Follow this workflow when reviewing code changes:

1. Check for correctness — does the code do what it claims?
2. Check for readability — can another developer understand it?
3. Check for security — are inputs validated and secrets protected?
4. Check for performance — are there obvious inefficiencies?
5. Check for tests — are new behaviors covered by tests?
6. Provide actionable feedback with specific suggestions.
