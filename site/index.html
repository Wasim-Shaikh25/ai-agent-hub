Why not just a router

Routers move tokens. We move context.

LLM router (LiteLLM / 9Router)

  • • Fallback & provider translation
  • • Stateless — one request at a time
  • • No shared memory across agents
  • • No code-aware retrieval or knowledge map
  • • No behavior governance or audit

AI Agent Hub

  • ✓ Shared context + memory across different agents
  • ✓ Code-aware hybrid retrieval + knowledge map
  • ✓ Gateway (fallback/routing/cost) as one component
  • ✓ RBAC, audit, cost dashboards, SSO
  • ✓ Self-host; data never leaves your network

The gateway is ~15% of the surface area — swappable. The value is the brain and governance on top, which no free router provides.
